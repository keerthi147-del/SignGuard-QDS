SignGuard

Sign a document

Your file is fingerprinted (SHA-256). The fingerprint decides the basis and bit of every quantum signature qubit, which are then teleported to the verifier. The file itself is not stored.

Verify a document

Upload the file you received and enter its signature ID. The verifier measures the stored qubits using the file you upload, so any change to the file breaks the match.
